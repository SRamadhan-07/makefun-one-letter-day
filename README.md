A Python program — standard library only, no network — that writes exactly one letter to /output/entry.txt: P, the initial of the word that describes the day — plot-twisted, a day that kept scheduling plot twists before coffee. The competition's gate is UTF-8 text of exactly 1 character, and the file is byte-identical on every run.

## Run it

```sh
python3 main.py
```
